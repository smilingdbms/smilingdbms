# RecruitBase Pro

Enterprise Recruitment Management System

## Stack
- Next.js 14 (React)
- Supabase (PostgreSQL + Auth + Storage)  
- Vercel (Hosting)
- Gemini AI (CV Parsing - Free)
- Tailwind CSS

## Setup
1. Run SQL schema in Supabase SQL Editor
2. Enable Google OAuth in Supabase Auth
3. Deploy to Vercel with env vars
4. Set first user as admin in Supabase

## Login
Google OAuth - one click sign in
